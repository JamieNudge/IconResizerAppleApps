# Repository vs local desktop builds

The `main` branch on GitHub ([IconResizerAppleApps](https://github.com/JamieNudge/IconResizerAppleApps)) is the **canonical source** for this clone.

Some desktop builds may show UI that is **not** in this repo (for example an Apple/Android “Store” toggle). That usually means either:

- Those changes were never committed or pushed, or  
- They come from a different folder or fork.

If you recover newer Swift sources, merge them here and push so GitHub and your machines stay aligned.
